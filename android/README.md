# AirFlow Android (prototype)

Native Android starter with Wi-Fi LAN discovery via DNS-SD (NSD), tap-to-send and receiver approval.

Both devices must be on the same local Wi-Fi network, with AirFlow open. Not equivalent to Apple's AirDrop or cross-platform native discovery. No production security/authentication yet; do not use for sensitive files.

Open the `android/` folder in Android Studio and build an APK. The project has not yet been compiled or tested on hardware. Native Mac/Windows/iOS apps are not yet implemented.
